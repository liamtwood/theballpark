Notes

  • Agent rail: 3 deep — Project → Supplier → Item. Supplier rail: 2 deep — Project → Item. Items are always the leaves.
  • Same item card on both views: name + status pill. Click = select that item thread on the right pane.
  • Supplier middle layer (agent only): .bp-list-row showing supplier name + count badge + latest snippet. The supplier viewer skips this — they ARE the supplier.
  • Status pill colours: use existing semantic tokens — --color-action (negotiating), --color-booked (signed), --color-quoted (payment processing).
  • Indent: each nested level uses .children wrapper with 16px left padding + soft left rule. Same primitive throughout.
  • Empty-state: empty rail just shows the hero + sidebar shell with no rows. Future prompts add data.
