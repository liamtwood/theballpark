How both homes work

  • Same layout: shell header → hero with cog → stats strip → 3-column body
  • Hero title reads "Hello, {firstName}" by default; configurable via page-settings drawer (Greeting · Username · Org Name · fixed text)
  • Stats strip: 4 quick numbers, persona-specific (agent: projects/briefs/credits; supplier: live/briefs/payouts/YTD)
  • Cog (⚙) on the hero opens the page-settings drawer — toggles section visibility, edits hero title/subtitle, picks theme accent
  • Centre launcher: 5 tiles per persona, first tile is the primary "Add" CTA (vivid gradient like the avatar)
  • Section cards are independently toggleable + each fetches its own data
  • Settings persist per org_type via the existing org_type_config table — admin edits cascade to all users in their org
  • Route is /home — canonical, no aliases, no redirects from other paths
