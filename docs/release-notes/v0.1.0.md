# v0.1.0

<!-- Release: v0.1.0 · Ballpark Base Release · 2026-09-16 12:00 · built from v2.464 -->

## Ballpark Base Release
- EP-00001 · New · **Agent** (event agency) — build a project from a brief, ballpark the cost, message suppliers, quote the client.
- EP-00002 · New · **Supplier** — list products, run a shop & storefront, respond to quote requests.
- EP-00003 · New · **Admin** — curate the taxonomy, approve items, manage roles & codelists.

## Projects
- EP-00004 · New · AI-first project creation from a written brief; a project workspace (Overview · Inbox · Ballpark Cost · Marketplace · Reports); cost estimate with quantities, margin, contingency, VAT & insurance; a live-project flow once suppliers are messaged.

## Marketplace
- EP-00005 · New · Browse by category → subcategory with dense item cards (Supplier · City) and Quick View; filters; available both globally and inside a project.

## Shop Front
- EP-00006 · New · **Supplier** — My Shop (your products) and My Shopfront (your brand page) on the shared Marketplace layout, plus a supplier home dashboard of what needs you.

## Items
- EP-00007 · New · Catalogue items with per-unit or flat pricing, units, install cost, tier, and an image gallery.

## Taxonomy & Categories
- EP-00008 · New · 15 macro categories with curated subcategories; browse + admin curation across the marketplace.

## Inbox
- EP-00009 · New · Per-supplier message threads with an inbox landing (per-supplier action rollups) and quote requests raised from a project.

## AI Agent
- EP-00010 · New · Parses a written brief into a structured project and suggests/matches marketplace items.

## SOW & Invoice
- EP-00011 · New · Client-facing quote document in an SOW layout (timeline, payment terms, special terms) with themed presentation.

## Clients
- EP-00012 · New · Client records (company details, address) attached to projects and reusable across them.

## Coachmarks
- EP-00013 · New · In-app guided help — contextual coachmark tips that explain features as you go; admins can tweak the copy.

## Platform & Admin
- EP-00014 · New · **Approval** — admin approves item imagery before it goes live; suppliers submit and resubmit; text & pricing edits don't force re-approval.
- EP-00015 · New · **Codelists** — centralised reference lists (statuses, units, etc.) driving consistent, controlled dropdowns.
- EP-00016 · New · **Feedback** — issue / enhancement / QC tracking (internal today; no customer-facing page yet).
- EP-00017 · New · **Security & Roles** — Google sign-in; org-based roles (agent / supplier / admin) with permissions re-derived per request; identity-only sessions.
