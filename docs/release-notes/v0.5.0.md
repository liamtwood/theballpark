## Platform
- EP-00XXX · New · **Rebuilt platform & isolated environments** — Ballpark rebuilt on a streamlined data model and promoted to its first **fully-isolated** preview environment: its own database, backend and frontend, with no shared infrastructure. Tenant isolation is enforced at the database itself (row-level security + a non-owner application role + per-request identity), hardened this cycle by a security audit — quote ownership pinned at the database, message parties made immutable, and supplier quote edits restricted to soft-delete.

## Projects & Running budget
- EP-00XXX · New · **Project delivery workspace** — a project now has two views: a draft **Ballpark quote** (scope + indicative costs) and an active **Running budget**. The budget shows supplier-first cards grouped by supplier — a per-supplier status pill, item rows (item · quantity · quick view · status · cost · subtotal), and payment tiles (paid · outstanding · final 50%) once a line is agreed — with a Draft ⇄ Active selector, a Details tab, and your own costs alongside.
- FR-00XXX · New · **Per-line negotiation status** — agency ↔ supplier negotiation is tracked as a journal of events; each line's status reads "To agree" through "All confirmed", shown consistently in both the inbox and the Running budget from one shared source.

## Project workspace
- FR-00XXX · New · **Project hero** — a running-ballpark pill shows the live total and item count; a chevron collapses the hero cover while the detail bar keeps the key stats and the project name.

## Marketplace
- FR-00XXX · New · **In-project marketplace** — the marketplace tab now scrolls at the window edge like the other tabs; Type (Items / Suppliers), filter and cart controls sit on one line above a full-width search, with the category rail aligned to the first row of cards.

## Workspace & settings
- FR-00XXX · New · **Single-row header & Projects rename** — a single-row app header (logo · navigation · account + Sign Out, pinned to the window edges); "Past projects" is now simply **Projects** throughout.
- FR-00XXX · New · **Editable status labels** — the status-pill wording is now editable in Settings ▸ Codelists (`line_display_status`), with the line, provider and quote status lists seeded.
