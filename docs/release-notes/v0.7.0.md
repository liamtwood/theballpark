## Inbox & conversations
- FR-00XXX · New · **Two-axis line status** — every line now shows both the deal state and whose turn it is. A line waiting on you reads "Reply needed"; one you've answered reads "Replied"; and whenever the other party made the last move, the status is shown in **bold** so it stands out at a glance.
- FR-00XXX · New · **Quote requested → Agreeing cost** — a briefed line reads "Quote requested" until the supplier engages, then moves to "Agreeing cost", so you can see which enquiries a supplier has actually picked up.
- FR-00XXX · New · **Redesigned Inbox cards** — full-width rows with a date circle that carries an action indicator (pink when it needs you, a tick once handled), the project name, a cost + status rollup, and a hover mini-table of the items. Agents can group the list by Project or by Supplier.
- FR-00XXX · Improved · **Conversation dates** — conversations now group messages under day dividers (Today / Yesterday / weekday / date), and the inbox rail shows the date of the last response.
- FR-00XXX · Changed · **Messages is now the Inbox** — renamed throughout, with a configurable hero and a per-organisation subtitle. The item card sits above the latest message and the page scrolls like the rest of the app.

## Supplier experience
- FR-00XXX · New · **Supplier inbox parity** — suppliers get the same Inbox as agencies: project rows that open the project view, item rows that open the full thread, and a Messages (N) badge in the navigation.
- FR-00XXX · New · **"Your shop" on the supplier home** — a card with published and awaiting-review counts and a quick way into My Shop.

## Supplier profile
- FR-00XXX · New · **Redesigned profile** — a banner cover with a circular logo, the organisation name with an approved check and "Approved Ballpark supplier · location", click-to-edit About Us, and contact pills for website, Instagram, email and company number.
- FR-00XXX · New · **Past projects** — show up to four hero images of work you're proud of, each with an optional description. These are the same images producers see in Quick View.

## Projects
- FR-00XXX · New · **Add an item to an active project** — pick how it settles (against the balance or 50% upfront) and which supplier to reach out to, with an editable brief.
- FR-00XXX · Improved · **Projects page** — Current and Completed as centred pills, a New project button in the hero, and a clearer empty state.

## Navigation & marketplace
- FR-00XXX · Changed · **Tidier navigation** — the Shopfront tab is hidden for now on Profile and My Shop, and the supplier Projects tab is hidden while that view is reworked.
- FR-00XXX · Improved · **Marketplace** — removed the "[Supplier] Store" link from supplier cards, and kept the marketplace cards a consistent size.
