# v0.4.0

<!-- Release: v0.4.0 · Variants, tags & quote pricing · 2026-09-27 · built from v2.653 -->
<!-- Curated for the demo promote. Headline features from the variants/store arc + quote wiring. -->

## Store & Variants
- new: Item variants — suppliers configure choices as variant dimensions (e.g. Size, Paper Type, Colour); each value is priced as No cost, an Upcharge (+£), or an absolute Cost. Edited inline in the item editor.
- improved: Options folded into variants — one consistent model, including free "pick one" choices like colour. The old separate Options list is retired.
- new: Tags & Tier are now editable in an item's Classification, with a one-click "What's Hot" tag (Tier gains Bronze / Silver / Gold).
- improved: Item descriptions keep their formatting (bold, bullet lists) from the supplier's own site.

## Marketplace
- new: What's Hot — a store's shopfront leads with its What's Hot items and surfaces a What's Hot menu link when it has any.
- improved: Variant products show a configurator — pick the options, see the price update, with the cost shown on hover — and require a choice before adding to a ballpark.
- improved: Supplier cards and the project Suppliers tab polish carried over from v0.3.x.

## Quotes
- new: The chosen variant carries into the quote — the option ("Ivory · Bedazzled") shows on the line, the cart, the preview panel and the client quote document.
- new: A variant's upcharge prices per unit on top of any volume tier (e.g. £2.99 + £0.50 = £3.49 each).
- new: Set the quantity directly in the item dialog.

## Polish
- fixed: The item dialog's close button now fully closes the preview.
- fixed: Per-unit prices show pence where present, so unit × quantity reconciles with the line total.
