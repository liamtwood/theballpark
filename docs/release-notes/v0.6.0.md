## Catalogue & My Shop
- EP-00XXX · New · **Bulk item management** — select several items at once — in card, list or table view — and act on them in one pass: make active / inactive, submit for approval, approve / reject (admins), reclassify into another category, delete, or refresh their images. Available to suppliers on their own shop and to Ballpark admins across shops, with each action gated to who may perform it.
- FR-00XXX · New · **Image filter + Refresh Images** — filter a shop by whether an item has a photo (Any / Yes / No), and re-pull images for the ones missing them straight from the source listing — fixing imageless items without a full re-import.
- FR-00XXX · New · **Reclassify from the item** — move an item (or a whole selection) into a different category from one dialog that opens on the item's current home; the category rail refreshes on the spot — no page reload — when items are reclassified or added.

## Catalogue onboarding
- FR-00XXX · New · **Resume a website analysis** — analysing a supplier's website now persists, so you can start it, step away, and come back to the results rather than re-running it. Image pulls prioritise a listing's own product photos within the fetch budget.

## Marketplace
- FR-00XXX · New · **Clearer filters** — each marketplace filter now carries a label above it — Price / Tier / Status / Active / Images — in the same style as an editable form field, with plain Any / Yes / No choices where it fits; the filter control and the single-supplier store header were tidied to match.

## Platform & security
- FR-00215 · Changed · **Cross-org write lockdown** — a Ballpark admin can no longer edit another organisation's items simply by being an admin. Admin reach is now read-only except for two narrow, column-scoped actions enforced at the database itself: moderation (approve / reject and soft-delete) and the image refresh (images only). Hardened by an end-of-arc security and Angular audit this cycle.
